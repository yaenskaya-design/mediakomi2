# 🏠 Медиакоми — Симулятор оценки недвижимости

Интерактивный веб-сервис для тренировки навыка оценки стоимости квартир в Республике Коми.

## Описание

Пользователю показываются реальные объявления о продаже квартир. Задача — угадать цену, передвигая бегунок. После 10 раундов подсчитывается результат и определяется тип инвестора.

## Механика

1. **Старт** — 10 случайных объявлений из базы
2. **Раунд** — фото + описание квартиры → бегунок с ценой → кнопка «Оценить»
3. **Результат раунда** — правильная цена, разница, баллы (0-100)
4. **Итог** — общий счёт и вердикт:
   - 💰 **Щедрый инвестор** — переплачиваете за недвижимость
   - 🎯 **Опытный инвестор** — близки к реальным ценам
   - 🤏 **Скряга** — экономный подход, недооцениваете

### Система баллов

| Отклонение от реальной цены | Баллы |
|---|---|
| ≤ 2% | 100 |
| ≤ 5% | 90 |
| ≤ 10% | 75 |
| ≤ 15% | 60 |
| ≤ 20% | 45 |
| ≤ 30% | 25 |
| ≤ 50% | 10 |
| > 50% | 0 |

## Технологии

- **React 18** + TypeScript
- **Vite** — сборка
- **Tailwind CSS** — стилизация
- Основной цвет: `#0050cf`
- Mobile-first дизайн
- Без тяжёлых зависимостей

## Запуск

```bash
# Установка зависимостей
npm install

# Режим разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```
